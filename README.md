## Overview

**Spring Boot Prerequisites** is a structured learning repository designed to build **strong backend fundamentals** before starting Spring or Spring Boot.

Instead of jumping directly into frameworks, this repository focuses on the **core concepts Spring Boot is built upon**, helping learners understand *why things work*, not just *how to use them*.

Completing this repository prepares you to learn Spring Boot **confidently, logically, and without confusion**.

---

## Why this repository exists

Many beginners face difficulties when learning Spring Boot because they:
- memorize annotations without understanding
- struggle with dependency injection and repositories
- feel lost while debugging errors
- lack clarity in backend interviews

This repository addresses those problems by strengthening the **foundation first**.

> Frameworks evolve. Fundamentals endure.

---

## Who should use this repository

This repository is suitable for:
- Beginners planning to learn Spring or Spring Boot
- Students preparing for backend internships or entry-level roles
- Developers who feel confused while working with Spring Boot
- Anyone who wants a clear backend learning path

No prior Spring or Spring Boot knowledge is required.

---

## What you will learn

By completing this repository, you will gain clarity on:

- Java fundamentals and object-oriented programming
- Exception handling and collections
- Java memory basics
- SQL and relational databases
- JDBC and its limitations
- Maven and dependency management
- XML and JSON fundamentals
- Hibernate and ORM concepts
- JPA and persistence basics
- Spring Data JPA concepts
- Layered backend architecture

Most importantly, you will understand **how all these concepts connect inside Spring Boot**.

## How to use this repository

Follow the folders **in sequence**.

For every topic, focus on:

- What the concept is  
- Why it exists  
- What problem existed before it  
- Simple and clear examples  
- Common beginner mistakes  
- How Spring Boot uses it later  

This repository is designed for **understanding, not speed**.
